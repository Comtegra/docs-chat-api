# docs-chat-api

Docs Chat is a self-hosted AI assistant for your documentation, deployed in your own CGC namespace. One instance serves one documentation site: your database, your index, your LLM key. The service keeps a chunked copy of the docs in pg-vector, picks the relevant passages with hybrid search (cosine + full-text, RRF fusion) and has the model answer **strictly from them**, with numbered citations `[n]`. Nothing is trained; models are served through the CGC LLM gateway; nothing leaves CGC.

Configuration is pure environment with sane defaults: two required secrets (`DATABASE_URL`, `OPENAI_API_KEY`) plus a few optional knobs; the import key is generated by the service itself (RAW printed once in the boot log, hash in the database).

## Development

```bash
npm ci
npm test                     # node --test, offline
cp .env.example .env         # fill in the database and the LLM key (template with comments)
npm run db:migrate           # schema_migrations + pgvector (reads .env)
npm start                    # PORT=3001; curl -s localhost:3001/api/v1/health
```

Local database without installation:

```bash
docker run -d --name docs-chat-db -e POSTGRES_PASSWORD=dev -p 5433:5432 pgvector/pgvector:pg16
```

`npm start` and `npm run db:migrate` read `.env` automatically (`--env-file-if-exists`, node ≥ 22.9); a variable set in the environment wins over the file. `.env` is gitignored — template: `.env.example`; the full list of variables with defaults lives in the code (`lib/tenants/envConfig.mjs`).

## Releasing (maintainer)

1. Bump the version in `package.json`, push to `main`.
2. Tag `api-x.y.z` → GitHub Actions (`.github/workflows/ci.yml`): tests + lint + kit tests, then the image is pushed to `ghcr.io/comtegra/docs-chat-api:api-x.y.z` (and `latest`). The package is public — users pull it without a pull secret.
3. Deployments go through the CGC platform (compute recreate with the new image), never through CI.

## docs-chat kit

[`docs-chat-kit/`](docs-chat-kit/) — two Python scripts (`md_to_json.py`, `send_json.py`) plus ready CI workflows (GitHub Actions, GitLab) that turn a Markdown repository into an indexed corpus. Users get it as ZIPs from the documentation site; `python docs-chat-kit/package.py` builds them.
